## 📌 The business problem

Pricing an IT-services deal means bringing together many moving parts: which people work on it, for how long, at what cost,
and with what margin. Done in spreadsheets, this is slow, error-prone and hard to review, and every new version of a quote
gets harder to track.

## ✅ What the tool does

| Area | What it provides | Value for the business |
|---|---|---|
| 📋 **Deals pipeline** | Every deal with account, owner, priority, service line and status (Draft → In Progress → Submitted → Won / Lost) | One place to see and track all deals |
| 🧮 **Commercial estimates** | Total cost, average margin, additional cost, total price and blended rate for each commercial | Accurate, consistent pricing |
| 🕓 **Version history** | Each commercial keeps its versions, so changes to a quote are traceable | Easy review and approval |
| 👥 **Resource loading** | Plan which resources work on a deal and how much of their time is needed | Realistic cost and staffing |
| 📊 **Dashboard** | Overview of deals and their progress | Faster decisions for managers |
| 🔐 **Role-based access** | Google sign-in, with actions shown according to each user's permissions | Right people see the right actions |
